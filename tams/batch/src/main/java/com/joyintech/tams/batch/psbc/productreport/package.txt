批处理说明
批处理名称：理财报表生成批处理
批处理主要功能：
        生成 理财产品状态表(FIN_PRODUCT_STATUS) 理财产品信息表(FIN_PRODUCT_INFO) 数据
        是否生成数据需要在 报表生成配置表(REP_BATCH_CONFIG) 中配置参数

测试:
1.新建产品
2.产品登记编码管理
其中 产品名称	产品登记编码	行内标识码	理财产品代码 必填
3.批处理启动 产品基本信息接口数据接入 -> 数据写入 CHB_PRD_BASEINFO
4.产品认购
5.资产交易
6.批处理启动_估值 批处理统一启动
7.查看 监管报送-中债信息报送登记-产品募集总量登记(CHB_PRD_RAISETOT_SUB) 该数据影响理财产品信息表
8.产品申购
9.批处理启动_估值 批处理统一启动
10.查看 监管报送-中债信息报送登记-产品存续期登记(CHB_PRD_BASEINFO)该数据影响理财产品状态表
11.产品到期
12.查看 监管报送-中债信息报送登记-品终止登记(CHB_PRD_END_SUB)该数据影响理财产品信息表
13.批处理启动_估值 批处理统一启动 (月末)

注:理财报表生成批处理不用单独启动 在 批处理启动_估值 批处理统一启动 月末时会自动处理
