### 2.3. 发布内容

1. 基础数据管理

   银行间&交易所费用升级

2. 产品端管理

   支持对未来回补信息的新增和修改（主要是回补形式、利率）

3. 组合管理

​       1）质押券查询：增加字段展示质押券当前持仓，剩余可质押券面

​       2）组合模拟试算

​       3）实时资产头寸查询：支持同时查询多个组合代码

4. 投资交易

   1）资产转仓：支持多组合内部转仓，包含业务类型：债券、基金、计划类资产（利率型）、计划类资产（净值型）、存款、项目类资产

   2）基金分红方式管理：非货币基金支持同时两种方式分红，分红方式应该按照账户的维度处理

   3）公募基金交易：增加多组合新建

   4）合作资产费用支付管理：增加多组合新建

   5）应收款查询：多次结清模块无法判断是哪个产品支付

   6）回购交易：的查询支持选择通道和抵押品查询

   7）内部交易撤销其中一条时另一条也联动撤销

   8）债券交易：增加自动加券功能，提升操作效率

   9）债券和回购交易费用相关

   10）投资费用支付

5. 估值核算

   1）支持账套组查询

   2）交易所债券存续期交易支持交易所债券提前付息

   3）支持账户维护费预提功能

   4）所有者权益变动表-菜单名称修改为“净值变动表”

   5）交易所债券卖出确认增值税算法升级：卖出当天的利息是单独计算利息还是合并到历史中一并计算

6. 风险管理

   1）支持现金管理类风险指标

   2）授信要穿透底层的

   3）授信多个生效日要能继承的、支持空档期

   4）风险试算违规增加参数控制

   5）交易页面是否展示风险试算配置化

7. 监管报送

   1）人行及银保监新增报表：表1~表7及银行理财产品投资资产及整改情况，共8张报表

   2）批处理启动：【批处理启动】在跑批时，没选产品，中债人行批处理没做到隔离

   3）产品登记编码需要支持新建功能

8. 系统管理

   1） 增加批处理：产品未来计划批处理 、 市场日历接入后计划更新 

   2）工作流配置：支持多级法人模式

   3）工作流管理：支持通过页面配置各业务工作流模板

   4）主动提醒：通过主动提醒直接跳转到办理页面

9. 数据管理

   资产标的数据维护，可以对接收来的资产在中债子系统进行独立维护，并进行中债标准check

10. 功能升级

    宁波银行的产品化需求、最新的G06、银行月度表升级改造(含联社版），满足银行版、子公司版（联社版不支持）

11. 一二期直连

    实现一二期10个报送报表的中债直连功能

12. 版本回归

    1）对老版本的数据抽数功能进行回归测试，直连的时候对数据流向有影响，需要测试；
    2）平顶山产品化内容移植到2.1.6，并进行回归测试；
    3）业务数据维护功能的升级、已经中债标准check的测试工作；

13. 投资者质量核查

14. 修复回馈主产品问题179个，工单问题未统计在内，详见[主产品问题修复清单](https://svn.joyintech.com/svn/ZGCPBS/3-受控库/产品基线/tams-V2.1.6 build20210331/主产品问题修复清单)
