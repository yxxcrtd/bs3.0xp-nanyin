1:开通ftp或者sftp上传和下载权限(包含读取文件存储目录，下载存放目录)
2:创建当前tamsuser用户，授予775权限
	chmod 775 tamsuser
3:创建表空间(两个正式，两个临时)
 	正式表空间
	create  tablespace BASE_DATA tempfile '${ORACLE_HOME}\oradata\BASE_DATA.bdf' size 1024m reuse autoextend on next 500m maxsize unlimited; 
	create  tablespace MAST_DATA tempfile '${ORACLE_HOME}\oradata\MAST_DATA.bdf' size 1024m reuse autoextend on next 500m maxsize unlimited; 
	临时表空间
	create temporary tablespace BASE_DATA_TEMP tempfile '${ORACLE_HOME}\oradata\BASE_DATA_TEMP .bdf' size 50m  autoextend on  next 50m maxsize 20480m  extent management local;
	create temporary tablespace MAST_DATA_TEMP tempfile '${ORACLE_HOME}\oradata\MAST_DATA_TEMP .bdf' size 50m  autoextend on  next 50m maxsize 20480m  extent management local;
4:创建数据库用户（base和mast两个数据库用户）
	create user TAMS_BASE identified by TAMS_BASE default tablespace BASE_DATA temporary tablespace BASE_DATA_TEMP 
	create user TAMS_MAST identified by TAMS_MAST default tablespace MAST_DATA temporary tablespace MAST_DATA_TEMP 

5:给TAMS_BASE,TAMS_MAST两个用户授权
	--grant dba to TAMS_BASE;
	--grant dba to TAMS_MAST;
	grant connect,resource to TAMS_BASE;
	grant create any table to TAMS_BASE;
    grant drop any table to TAMS_BASE;
	grant select any table to TAMS_BASE;
	grant delete any table to TAMS_BASE;
	grant update any table to TAMS_BASE;
	grant insert any table to TAMS_BASE;
	

	grant connect,resource to TAMS_MAST;
	grant create any table to TAMS_MAST;
    	grant drop any table to TAMS_MAST;
	grant select any table to TAMS_MAST;
	grant delete any table to TAMS_MAST;
	grant update any table to TAMS_MAST;
	grant insert any table to TAMS_MAST;

------------------------下面编码格式特别注意-------------------------------------
6:根据当前机器的oracle编码格式，调整对应的sql文件格式
7:sqlplus TAMS_BASE 数据库
	执行data下base中create,init,delete,sql_addtional中执行语句，按照编号顺序依次执行
8:sqlplus TAMS_MAST 数据库
	执行data下mast中create,initdata,sql_addtional中执行语句，按照编号顺序依次执行
9:部署war包，注意配置文件的使用，避免菜单出现不正确的显示，发版给现场的配置文件已经纠正好了，现场同事只需要更改数据库配置，和日志存放位置即可
